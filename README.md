# Qbittorrent Service

Qbitrorrent is a torrent download service. You can add and control your torrents from your browser.

For more information about Qbittorrent click [here][Qbittorrent site].

## How to install and run

- First make a copy of the ".env.example" file and rename it to ".env";
- Fill the required variables in the .env file;

After that you can run the command:

`docker-compose up -d`

[Qbittorrent site]: https://www.qbittorrent.org
